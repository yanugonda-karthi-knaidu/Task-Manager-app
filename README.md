## Task Management Web App

The Task Management Web App is a simple, user-friendly web application designed to help users manage their tasks efficiently. Built as a project for my college course, this app allows users to create, edit, and delete tasks, with the ability to categorize them by priority and due date. This app serves as a great solution for managing everyday tasks and staying organized.

## Features
- Create tasks with titles, descriptions, and due dates.
- Set priority levels and categories for each task.
- Edit or delete tasks when necessary.
- Mark tasks as completed.
- Responsive UI for optimal usage on both desktop and mobile devices.
- Intuitive task bar with an 'Add New Task' button to quickly add tasks.

## Technologies Used
This project is built using the following technologies:

- HTML: For structuring the content and layout of the app.
- CSS: For styling the app, ensuring a responsive and clean design.
- JavaScript: To add interactivity, such as adding and deleting tasks, updating task status, etc.
- Local Storage: Used for storing tasks in the browser so that the data persists even after a page refresh.


## Working of the Task Management App
- Task Creation: Users can add new tasks by clicking the "Add New Task" button. Each task can have a title, description, due date, priority, and category.
- Task Display: All tasks are displayed in a list, where each task shows the title, description, due date, and priority.
- Task Editing: Users can edit a task by selecting it from the list and making the necessary changes.
- Task Deletion: Tasks can be deleted from the list once completed or if no longer needed.
- Task Completion: Users can mark a task as completed, which visually distinguishes it from ongoing tasks.
